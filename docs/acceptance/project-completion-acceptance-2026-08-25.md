## 主要新增验收入口

无需登录即可检查：

- `/organizations`：机构目录；`/organizations/[organizationId]`：机构详情和申请状态。
- `/cities/[citySlug]`：动态、活动、机构、成员、政策五个城市分区。
- `/activities/[activityId]`：完整活动信息和状态驱动报名。
- `/members/[userId]`：成员统计、城市、活动和分页动态。
- `/policies`、`/policies/[policyId]`：城市筛选、来源、修订和废止展示。
- `/knowledge/[slug]`、`/insights/[slug]`：安全富文本、作者、来源和核验信息。
- `/help`：数据库 FAQ 与工单提交。

登录后检查：

- `/me/applications`：机构申请和帮助工单会话。
- `/me/notifications`：单条/全部已读和业务目标跳转。
- `/me/follows`：成员关注和加入城市。
- `/me/sessions`：设备信息、风险提示和会话撤销。
- `/me/appeals`：申诉补充与重新提交。
- `/api/account/export`：导出当前账号拥有的数据。
- `/admin/content`：知识、洞察、政策、FAQ 内容运营。
- `/admin/activities`：活动审核与参与人签到/缺席管理。
- `/admin/tickets`：工单受理、回复和解决。

## 建议验收顺序

1. 按“主要新增验收入口”检查页面与现有视觉风格是否一致。
2. 在隔离 staging 执行 `0012`、`0013` 迁移并运行种子数据。
3. 配置 PostgreSQL、Redis、OSS 和内容安全后，运行完整集成/E2E，保存测试报告。
4. 使用平台管理员和城市管理员账号分别验收数据范围与后台操作。
5. 执行 OSS 生命周期、Worker 重试/死信、注销匿名化和数据导出抽样。
6. 由运维完成 CI、镜像、Terraform、部署、压测、灰度、回滚和灾备证据；由法务完成政策签署。

只有第 2～6 步中的真实环境门禁全部通过后，才应将项目状态标记为“可正式生产上线”。
